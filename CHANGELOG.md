# Changelog

All notable changes to StoneChests are documented in this file.

## 1.0.5

- Fixed the navigation compass slot detection in open chest inventories.
- Left-click the temporary compass for the next page; right-click for the previous page.
- Protected page transitions from the inventory-close event emitted by `openInventory()`.
- Added orphaned hologram cleanup for loaded chunks.
- Strengthened navigation-compass protection against movement, drops, swaps, and stale items.
- Reworked the English documentation and release metadata.

## 1.0.0

- Initial release with Stone, Iron, and Diamond multi-page chests.
